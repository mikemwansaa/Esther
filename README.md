
# Esther's Birthday Website 🎂💗

A simple interactive birthday website made especially for Esther.

### Features

* 🎂 Interactive birthday cake and candles
* 🎤 Blow-to-extinguish candles using the microphone
* 💌 Personalized birthday message and wishes
* 📸 9-photo gallery
* 🎵 Birthday music section
* 💖 Floating hearts and pink-themed animations
* 🎁 Final birthday surprise

Built with **HTML, CSS, and JavaScript** and designed to work smoothly on both desktop and mobile.

Happy Birthday, Esther! 🎉💗
